# SNS Stream - 系統架構文件

## 專案概述

SNS Stream 是一個網頁自動化測試工具，專門用於測試直播大廳系統的各項功能。本工具使用 Playwright 模擬真實用戶操作，自動執行多項檢查並生成詳細的測試報告。

### 專案定位

- **類型**：自動化測試工具 / QA 輔助系統
- **用途**：SNS Stream 功能驗證、回歸測試、視覺化驗證
- **執行方式**：Web-based 操作界面 + 自動化腳本執行

## 技術棧分析

### 後端技術

#### Node.js 運行環境
- **版本要求**：>= 18.18.0

#### Express 框架
- **職責**：API 路由管理、靜態檔案服務、WebSocket 狀態同步。

#### Playwright 自動化框架
- **職責**：瀏覽器控制（Chromium）、頁面導航、元素操作、截圖與 Debug。

### 前端技術

#### 純 HTML/CSS/JavaScript
- **無框架設計**：輕量快速，直接部署。
- **主要特性**：即時進度更新、執行紀錄追蹤 (Run History)、視覺化統計。

## 專案結構

```
stream-lobby/
├── server.js                        # 主伺服器入口
├── routes/                         # API 路由模組 (check.js, check2.js, check3.js)
├── scripts/                        # 工具腳本 (steps/, steps2/, steps3/)
├── public/                         # 前端靜態檔案 (index.html, test2.html, sac.html)
├── logs/                           # 日誌檔案
└── documents/                      # 專案文件
```

## 系統特性

### 1. 三工具設計
- **Lobby**：13 項核心功能測試。
- **Live Slot**：16 項進階功能測試。
- **SAC 後台**：7 項後台與遊戲壓力測試。

### 2. 即時進度反饋
- 前端輪詢機制，即時更新測試狀態。
- 測試結束顯示 `測試完成: X 通過 / Y 失敗`。

### 3. 執行紀錄 (Run History)
- 自動記錄每次測試的時間、結果與網址，儲存於瀏覽器記憶體中。

### 4. 完整日誌與視覺化 Debug
- 所有 console 輸出自動記錄。
- 關鍵步驟自動截圖。

## 總結

SNS Stream 採用高度模組化的架構，將 UI、伺服器、與測試邏輯完全解耦。這種結構不僅提高了程式碼的可讀性，也使得添加新功能或修改現有邏輯變得非常安全且快速。
