# Live Slot (互動流) 測試規範

## 測試項目列表 (共 18 項)

1. **彈窗檢查**：驗證進入頁面時的 Stream n'Spin 彈窗是否正確出現並可關閉。
2. **開啟直播間**：從 Streaming Now 區域點擊卡片並驗證新分頁是否成功開啟。
3. **WebSocket Join 資料抓取**：攔截 `join` 封包，精準映射主播、帳號、餘額與幣別資訊。
4. **版本號檢測**：從直播間全域變數中自動抓取 `window.gVersion`。
5. **How to play**：驗證並關閉遊戲說明彈窗。
6. **MAX 按鈕測試**：驗證投注金額是否能一鍵切換至最大值。
7. **MIN 按鈕測試**：驗證投注金額是否能一鍵切換至最小值。
8. **Bet +**：驗證投注金額遞增功能。
9. **Bet -**：驗證投注金額遞減功能。
10. **Spin Round +**：驗證自動旋轉次數遞增。
11. **Spin Round -**：驗證自動旋轉次數遞減。
12. **Play 按鈕測試**：啟動遊戲旋轉，並開始背景監聽單號封包。
13. **送禮測試**：驗證直播間送禮功能與封包攔截。
14. **送禮記錄測試**：驗證送禮後記錄是否正確出現在 UI 歷史中。
15. **聊天室視窗測試**：驗證禁字偵測與正常訊息發送功能。
16. **直播間音效開關測試**：驗證音效切換狀態與 UI 反應。
17. **Game History 視窗驗證**：驗證遊戲歷史彈窗開啟、My Bet 與 My Win 標籤切換。
18. **詳細注單交叉比對報表**：
    * **自動化比對**：將 WebSocket 實時監聽到的 `broadcast_payout` 封包與 UI 詳細注單進行 1:1 比對。
    * **精度焊死**：採用字串提取技術處理 19 位 Order ID，確保數據 100% 精準。
    * **專業報表**：提供大尺寸視覺化面板，包含 Time, Order ID, Buy Feature, Payout, Change Credit 等完整欄位。

## 🎨 UI 介面與報表功能

### 1. 大尺寸交叉比對面板 (Step 18)
* **視覺化標註**：一致筆數標註為綠色 ✅，不符筆數標註為粉紅背景與紅色 ❌。
* **數量驅動**：支持動態收集 20、50、100 筆單號，等好等滿才進行比對。
* **視窗焊死**：測試結束後瀏覽器保持開啟，方便人工對照詳細注單。

### 2. 全域測試紀錄 (Run History)
* **跨工具同步**：Lobby、Live Slot、SAC 三個工具均具備統一格式的歷史紀錄。
* **持久化存儲**：採用 `localStorage` 技術，保留最近 10 筆紀錄，切換頁面或重新整理不消失。
* **可展開詳情**：點擊歷史紀錄可向下展開 **「錯誤摘要面板」**，完整列出該次測試的所有失敗步驟（含編號）與原因。
* **判定統計**：每筆紀錄均標註執行時間、測試網址以及 Pass/Fail 數量。

### 3. 測試狀態同步
* 測試進行中 `Current Step` 顯示當前進度。
* 測試完全結束後，狀態會自動切換為 **「測試完成」**。

## 🔍 特殊判定邏輯
* **Lobby 第 4 項 (Streaming Now)**：
    * **嚴格判定**：偵測到任何主播頭像破圖即標記為 **失敗 (❌)**。
    * **資訊保留**：即使失敗，依然保留詳細的主播名單面板，並以紅色底線標註破圖項目，兼顧「外觀整潔」與「除錯便利」。
