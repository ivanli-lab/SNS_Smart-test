# Lobby 測試工具 (SNS Stream) 說明文件

本文件詳細說明了 **Lobby 測試工具** 的測試項目、技術實現及操作流程。

## 🎯 測試項目詳解 (共 13 項)

1. **gVersion 版號測試**：自動抓取 `window.gVersion` 並驗證格式。
2. **Stream n'Spin 彈窗測試**：驗證進入頁面時的廣告彈窗是否正確出現並可關閉。
3. **更名功能測試**：驗證用戶更名流程，包含 IDN 禁字攔截測試與成功更名驗證。
4. **Streaming Now 已開啟的直播間**：
    * **核心邏輯**：掃描當前正在直播的所有主播。
    * **破圖判定**：若偵測到任何主播頭像破圖，該步驟判定為 **失敗 (❌)**。
    * **詳細清單**：即便失敗，也會列出所有主播名單，並清楚標記破圖者。
5. **排序按鈕測試**：驗證大廳排序按鈕（先左後右）的點擊反應。
6. **Promotion 圖片檢查**：驗證活動推廣區域的圖片是否加載正常。
7. **All Streamers 圖片檢查**：
    * **區域鎖定**：精準掃描 "All Streamers" 標題下方的所有主播卡片。
    * **詳細清單**：列出完整主播名單，並以 **紅色加粗+波浪底線** 標記破圖主播。
8. **All Streamers 排列按鈕測試**：驗證下方主播區域的排列切換功能。
9. **直播主介紹卡片點擊測試**：驗證點擊主播卡片後是否正確開啟介紹視窗。
10. **Lobby 送禮功能**：
    * **動畫等待**：點擊確認送禮後自動等待 3 秒，確保送禮動畫播放完畢。
    * **餘額校對**：驗證送禮前後餘額變動是否與禮物金額一致。
11. **排行榜檢查**：
    * **視覺完整性驗證**：自動擷取 "All Times" 與 "Weekly Ranking" 前三名共 **6 個獎盃區域**。
    * **三排兩列佈局**：在報表中以大尺寸、高清晰度顯示截圖，方便人工視覺核對。
    * **零閃爍技術**：截圖瞬間凍結全網頁動畫，確保影像絕對靜止且不跳動。
    * **數據校對**：將 API 攔截到的排行榜數據與 UI 顯示數據進行 1:1 比對。
12. **直播主照片檢查**：驗證主播個人相簿中的照片規格與加載狀態。
13. **返回按鈕測試**：驗證 UI 的返回導航功能。

## 🎨 UI 介面與穩定性優化

### 1. 零閃爍渲染 (Differential Update)
* **技術**：前端實作「差異化更新」邏輯，只有在數據真正變動時才更新 DOM。
* **效果**：徹底消除每秒一次的暴力刷新感，讓 UI 穩如靜態網頁。

### 2. 佈局穩定化 (Layout Stability)
* **滾動條鎖定**：使用 `scrollbar-gutter: stable`，防止滾動條出現時內容左右晃動。
* **空間預留**：為大圖和細單預留坑位，防止內容載入時產生劇烈的上下推擠。

### 3. 執行紀錄 (Run History)
* **持久化存儲**：採用 `localStorage` 保留最近 10 筆紀錄。
* **可展開詳情**：點擊紀錄可查看該次測試的所有失敗步驟與原因。

## 🏗️ 模組化架構
所有測試步驟均位於 `scripts/steps/` 目錄下，具備高度獨立性與穩定性。
