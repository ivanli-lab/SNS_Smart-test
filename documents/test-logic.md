# SNS Stream - 測試邏輯總表

本文件彙整了 SNS Stream 旗下三款測試工具的核心邏輯、項目統計與技術標準。

## 1. Lobby (測試工具 1)
*   **項目數**：13 項。
*   **核心邏輯**：
    *   **視覺完整性**：即時擷取排行榜 6 獎盃大圖，並執行破圖自動判定。
    *   **數據對帳**：攔截 1021 封包進行 API 與 UI 數據 1:1 校對。
    *   **穩定渲染**：實作「差異化更新」與「滾動條鎖定」，確保 UI 零閃爍、不跳動。

## 2. Live Slot (測試工具 2)
*   **項目數**：18 項。
*   **核心邏輯**：
    *   **精度對帳**：攔截 `broadcast_payout` 封包，與 UI 詳細注單進行 19 位單號精準比對。
    *   **自動化控制**：完整覆蓋投注控制 (MAX/MIN/Bet+/-)、自動旋轉次數切換及送禮記錄驗證。
    *   **專業報表**：提供大尺寸交叉比對面板，清晰標註數據一致性。

## 3. SAC 後台 (測試工具 3)
*   **項目數**：7 項。
*   **核心邏輯**：
    *   **座標精準點擊**：基於百分比座標尺技術，精準命中 Canvas 遊戲按鈕。
    *   **智慧等待**：自動偵測 Free Game 狀態並執行「破冰點擊」，防止測試卡死。
    *   **視窗焊死**：測試成功後保留所有現場，禁止自動關閉。

## 🛠️ 全域技術規範

*   **自動化框架**：Playwright (Chromium)。
*   **狀態同步**：前後端輪詢機制，每 1000ms 更新一次。
*   **執行紀錄 (Run History)**：
    *   跨工具同步，持久化儲存於 `localStorage`。
    *   支援點擊展開錯誤詳情，完整保留步驟編號。
*   **佈局穩定技術**：
    *   `scrollbar-gutter: stable` 消除橫向晃動。
    *   `aspect-ratio` 預留坑位消除縱向跳動。
    *   「座標剪裁」截圖技術消除測試視窗抖動。
